# MySQL Handbook (React)
Simple lecture reader: lecture list on the left, theory + code on the right. Content is from the CodeWithHarry MySQL Handbook PDF.

    npm install
    npm run dev      # local
    npm run build    # dist/

Edit lectures in `src/data/lectures.js` (blocks: p, h, c = code, ul, tb = table, n = note, q = practice).
Deploy: push to GitHub, Settings > Pages > Source: GitHub Actions (workflow included).
